# Playwright QA Portfolio

End-to-end test automation framework built with Playwright and Python.

## Tech Stack

- Python 3.13
- Playwright
- Pytest

## Test Cases

- Google title validation
- Google search functionality

## How to Run

```bash
pip install -r requirements.txt
playwright install chromium
pytest tests/ -v
```
